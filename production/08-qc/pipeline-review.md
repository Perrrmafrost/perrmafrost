# PIPELINE REVIEW — tools/render.py

Adversarial review of the first version against the installed google-genai 2.21.0 source, run as a workflow: three refuters with distinct lenses (SDK contract, mocked execution, production fitness), then two independent skeptics per finding with a default of *refuted*. 55 agents, 26 candidate findings, **19 confirmed, 7 refuted.** Every confirmed finding is fixed in the current file and covered by `tools/test_render.py`.

| # | Sev | Finding | Fix |
|---|---|---|---|
| 1 | major | Operation error is swallowed: a failed op is reported as 'filtered/empty - no video returned' and the real API error never reaches the log or manifest | wait_for() checks op.error before reading the response and raises with the server's code/message. |
| 2 | blocker | Manifest dict mutated by worker threads while json.dump iterates it - render run crashes mid-way at the default --parallel 4 | Manifest mutations happen under the lock via record(); the file is written atomically (tmp + os.replace); saves happen inside the worker's try. |
| 3 | major | Operation that completes with `error` is reported as 'no video returned'; the server's error message is discarded | Same as #1. |
| 4 | major | Continuation pieces tell Veo to match 'the supplied reference images' while no reference images are sent | face_lock() is only emitted when plates are attached; continuation prompts say 'continue from the given frame' instead. |
| 5 | minor | speech_block emits an empty dialogue clause ('...not shouted: .') for shots whose only speaker is VOICE (O.S.) / SYSTEM VOICE | speech_block() handles VOICE (O.S.) and SYSTEM VOICE explicitly as off-screen voices; an empty clause can no longer be emitted. |
| 6 | minor | The default smoke shot SH0126 is 12 s, so 'one paid call' is actually two chained generate_videos calls | smoke prints the exact number of paid calls and generated seconds before proceeding. |
| 7 | minor | End-of-run summary and 'spent' total are computed over the whole manifest, not over this run | The end-of-run summary is scoped to the shots this invocation touched. |
| 8 | blocker | No retry/backoff anywhere; a 429 while polling abandons an already-paid operation and the op name is never persisted | Client is built with HttpRetryOptions(attempts=6, backoff to 60s, 408/429/5xx); with_backoff() wraps submit and poll; op.name is persisted as in_flight the moment it is accepted and resumed on the next run; a circuit breaker stops the pool after five consecutive 429s. |
| 9 | major | The 'smoke' shot is two paid calls, not one, and exercises none of the request shapes that ~40% of the plan depends on | Default smoke is a deliberate trio: a two-shot with dialogue, the double, and one chained shot with dialogue. |
| 10 | major | Continuation pieces of chained shots re-send the full dialogue block, so lines are spoken twice in 47 shots | Dialogue is assigned to pieces by time using the subtitle model's offsets; later pieces that have no lines say so. |
| 11 | major | Speaker attribution ignores who is in frame: 30+ singles have the off-screen spouse's line written as if spoken on camera | speech_block() labels a speaker who is not in the subject set as off-screen and out of frame, and single-subject shots state that only that person is in frame. |
| 12 | major | Negative prompt suppresses 'on-screen text' on the shots whose subject IS text on the pane | build_negative() keeps text allowed on the pane for shots where the pane carries text. |
| 13 | major | person_generation='dont_allow' on inserts that contain hands and spoken dialogue | needs_people() keys person_generation on plates, dialogue, or a body part in the prompt. |
| 14 | major | Lauren's only reference plate is 720x405 and it is used for 192 of the 272 face-locked shots | New plates: face-centred crops at 1024 px on the short side; Lauren gets a frontal and a three-quarter plate from the clip; two-shots carry all three slots. |
| 15 | major | Face-lock boilerplate contradicts the double's locked deviations and is attached to shots that have no reference images | face_lock() has a double-specific form (hair down, the scar, eyes on someone else) and is skipped without plates; the literal label 'Double' is gone from speech. |
| 16 | major | Operation errors are masked as 'filtered/empty - no video returned', hiding the actionable 400 on the first failure | Same as #1. |
| 17 | major | 15-minute hard timeout abandons a paid, still-running operation and the resume path re-pays for it | op_timeout is configurable (default 30 min); on timeout the shot is left in_flight with its op name and resumed next run. |
| 18 | minor | req_hash ignores the seed and the reference plate bytes, so editing plates or seeds does not invalidate cached renders | req_hash() includes the plate bytes, aspect, resolution, the per-piece prompts and (on Vertex) the seed. |
| 19 | minor | The Act 3 shout is directed 'not shouted ... quietly', contradicting the bible | Uppercase lines are directed as shouts. |
