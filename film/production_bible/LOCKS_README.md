# locks.json: token registry for shot writers

Write `{TOKEN.FIELD}` anywhere in a shot's PROMPT or NEGATIVE line (e.g. `{CHAR_TUT.SHORT}, {CHAR_TUT.WARD_B}, {CHAR_TUT.DMG_L2}, {CHAR_TUT.STATE_G1}`, `{LOC_KARNAK_QUAY.LIGHT_NIGHT}`, `{GRADE_NIGHT_ACTION.TEXT}`) and run `python3 shots_md2jsonl.py shots/seq_NN_shots.md`: it pastes the bible's exact wording from `production_bible/locks.json` and fails on any unknown token or field; run `python3 production_bible/validate_locks.py` after any bible edit.

237 tokens, 1090 fields.
